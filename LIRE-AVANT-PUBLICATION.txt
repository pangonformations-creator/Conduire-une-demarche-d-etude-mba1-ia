CAMPUS BOWL : PUBLICATION SUR GITHUB PAGES

1. Décompressez Campus-Bowl-GitHub-Pages.zip.
2. Déposez tous les fichiers et dossiers extraits dans votre dépôt GitHub, en conservant leur organisation. Ne déposez pas seulement le ZIP.
3. index.html doit être directement à la racine du dépôt. Conservez le fichier .nojekyll.
4. Dans GitHub : Settings > Pages > Source : Deploy from a branch > Branch : main > dossier : / (root) > Save.
5. Ouvrez l’adresse indiquée par GitHub lorsque la publication est terminée.

Le site est prêt à publier, sans installation ni compilation.
Les étudiants consultent le cas et les données, téléchargent le classeur et remettent un dossier écrit avec leur fichier Excel complété.
